# Student Performance Prediction System

## Project Overview

Student Performance Prediction System analyzes academic, lifestyle, learning-environment, and background factors to estimate a student's `Exam_Score`. It combines a FastAPI service with a React/Vite interface and the existing fitted machine-learning pipeline.

## Key Features

- Student performance prediction
- Explainable ML feature impact
- Deterministic AI Performance Insights
- User-scoped prediction history
- What-if performance simulator
- Student comparison
- CSV batch prediction with template and result downloads
- Student Performance PDF Report
- Analytics dashboard
- Model Performance view
- Browser-local account, profile, and settings management
- Responsive desktop and mobile UI

## Machine Learning

The project uses `data/raw/StudentPerformanceFactors.csv` and predicts `Exam_Score`. Predictor inputs are separated into numeric and categorical features. The preprocessing pipeline performs median imputation and standard scaling for numeric features, and most-frequent imputation plus one-hot encoding for categorical features. Evaluation uses a train/test split, and the project evaluates Linear Regression, Random Forest Regressor, and Decision Tree Regressor.

### Model Results

The current selected model is Linear Regression based on the existing evaluation:

| Model | MAE | MSE | RMSE | R² |
| --- | ---: | ---: | ---: | ---: |
| Linear Regression | 0.4524 | 3.2560 | 1.8044 | 0.7696 |
| Random Forest Regressor | 1.0730 | 4.6202 | 2.1495 | 0.6731 |
| Decision Tree Regressor | 1.7489 | 12.5250 | 3.5391 | 0.1139 |

## Recommendation System

Recommendations are generated by the existing data-driven recommendation logic using the submitted profile, model estimate, observed dataset patterns, and feature associations. They are not diagnostic or causal claims.

## Explainable ML

The explainability endpoint uses the fitted preprocessing transformer, transformed feature values, Linear Regression coefficients, and intercept. Each contribution is calculated from transformed feature value multiplied by its fitted coefficient. Categorical one-hot features are mapped to readable labels.

## AI Insights

AI Performance Insights are deterministic and local. They summarize the real prediction, model contributions, profile values, and existing recommendations. No external AI or LLM API is required.

## Architecture

```text
React/Vite frontend
        |
        v
FastAPI backend
        |
        v
Prediction / analytics / explainability / insights / report services
        |
        v
Existing fitted ML pipeline + dataset
```

The current prototype uses browser-local storage for account, profile, session, and prediction-history behavior. No PostgreSQL/database is required for the current prototype.

## Project Structure

- `src/`: FastAPI API, prediction adapter, preprocessing, recommendations, explainability, insights, and PDF reporting.
- `frontend/src/`: React routes, authenticated shell, forms, dashboards, history, comparison, simulator, insights, and batch workflows.
- `data/raw/`: Source dataset.
- `models/`: Existing fitted model artifact.
- `outputs/`: Existing evaluation metrics and figures.
- `notebooks/`: Project analysis and modeling notebooks.
- `tests/`: Focused backend validation modules.

## Installation

Create and activate a Python virtual environment, then install backend dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Start the backend from the repository root:

```powershell
uvicorn src.api:app --reload
```

The API is available at `http://localhost:8000`.

Install and start the frontend:

```powershell
cd frontend
npm install
npm run dev
```

The frontend is available at `http://localhost:5173`.

## Batch Prediction

Batch prediction accepts CSV files with the exact 19 predictor fields used by the model. `Exam_Score` is not an input and is rejected to prevent target leakage. The endpoint validates each row, returns successful predictions and row-level errors in a result CSV, and preserves recommendation categories and messages. The current prototype limits uploads to 5 MB and 1,000 rows.

Batch prediction does not create prediction-history records.

## Limitations

- Authentication and history are browser-local prototype features.
- There is no server-side database or password-reset flow.
- No external AI API is used.
- The model reflects the available dataset and its observed relationships; predictions are estimates and not guarantees.
- Production deployment would require server-side authentication, durable storage, secret management, and stronger operational controls.

## Future Improvements

Future work could include server-side identity and durable storage, broader evaluation data, and production deployment controls. These are not part of the current prototype.
